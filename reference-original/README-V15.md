# CLOSEISH V15 – 200 000+ lakosú városok

4. nap, 5. kérdés: kizárólag minimum 200 000 lakosú városok a megadott adatkészlet szerint. A geokódoló ellenőrzi a lakossági küszöböt is. A korábbi, csak név/koordináta alapján betöltött városok eltávolítva; 105 korábbi adat egyeztetve + Aksu (Kína), mindegyikhez forrás alapján igazolt >=200 000 fős népesség. Internet mellett a 2020.12.05-én rögzített, 11 276 rekordos worldcities.csv alapján a játék további nagyvárosokat tölt be. Az online geokódoló a népességi adatot is ellenőrzi.

Az eredeti 4792 km-es célt 4793 km-re korrigáltuk, hogy az Aksu nevű, forrás szerint 340 020 lakosú város pontosan 1200 pontot kaphasson.

Forrás: https://github.com/PhilipWaldman/world-cities/blob/3151130cb4a2efd925f2afd6435215652f948463/WorldCities/worldcities.csv
Nyílt geokódolás: https://open-meteo.com/en/docs/geocoding-api

A népességadat történeti snapshot, nem 2026-os népszámlálás. A külvilág pontos, naprakész településlefedettsége offline nem bizonyítható. A korábban ismert, de <200 000 fős település 0 pontot kap.
