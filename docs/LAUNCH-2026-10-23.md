# CLOSEISH V17.7 – 2026-10-23: first playable date

- First playable day: **2026-10-23**, day #001 (original day #001 shifted from 2026-10-22).
- Seven included published days: **2026-10-23 through 2026-10-29**. Each of the previous V17.6 content days is shifted forward one day without losing a question day.
- The API refuses dates older than the launch for dated questions, starts, answer submissions, signed imports, and statistics. The frontend only receives launch-or-newer published dates.
- Each player's existing PostgreSQL results, progress and score-counter rows are moved +1 day by migration `004_shift_launch_to_oct23.sql`; their stored content-revision hashes are updated to match the new JSON. This prevents old results from being incorrectly shown as the new question set on the same calendar date.
- **Before deploying**: Back up the database and coordinate a short maintenance period because the old running API could otherwise write against the data while the migration runs.
- Previously issued signed receipts encode the **old date** and revision. In-flight unsynchronized V17.6 response receipts cannot be migrated cryptographically; a player with an active unfinished run should finish before cutover, or may need assistance afterward. Do not reset all saved data.
- The historical 2008 vehicle question now uses **kilometres** for question, limit, answer measurements and score boundaries. Its original US MPG source is retained only as provenance; points and direction are preserved.
- Install the **V17.7 backend first**, then the **V17.7 frontend**, and clear any CDN HTML/JS caches. Railway's preDeployCommand runs `npm run migrate`.
- No new PostgreSQL table is created, but migration 004 **is required** on databases initialized with V17.6.
